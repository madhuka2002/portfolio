## Overview

Quantheonix addresses the complexity of integrating AI capabilities into web applications through a reusable backend service for AI-powered conversations. It exposes a clear REST API and is designed so the model integration layer can support additional providers in the future.

## What I built

- AI integration with configurable model identifiers
- Streaming AI responses and an extensible AI service layer
- Request validation, structured error handling, logging, and CORS configuration
- Docker containerization for repeatable deployment
- Pytest coverage for backend behavior
- A Next.js interface and reusable React chatbot widget published as `@quantheonix/chatbot`

## Next phase

**Technologies:** Python, FastAPI, AI API, REST APIs, Docker, Pytest, and Next.js.
