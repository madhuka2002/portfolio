## Introduction

TED ME addresses the limitations of tightly coupled e-commerce systems through an event-driven architecture with independently managed services. User, product, and order operations are separated to improve modularity, maintainability, and deployment flexibility.

## Features

- **Event-Driven Microservices**: Decoupled services communicate through Apache Kafka.
- **API Gateway**: Spring Cloud Gateway centralizes request routing.
- **JWT Authentication**: Token-based access secures protected operations.
- **Dockerized Setup**: Services run in isolated containers.
- **PostgreSQL Persistence**: Relational data storage for platform services.

## Technologies Used

- **Language**: Java
- **Build Tool**: Maven
- **Framework**: Spring Boot
- **Communication**: Apache Kafka
- **Gateway**: Spring Cloud Gateway
- **Security**: JWT
- **Containerization**: Docker
- **Database**: PostgreSQL

## Architecture Overview

The system is composed of several microservices, each responsible for specific functionalities:

- **API Gateway**: Routes client requests to the appropriate service.
- **User Service**: Manages user data and authentication operations.
- **Product Service**: Manages catalog and product operations.
- **Order Service**: Manages order workflows.

Services publish and consume events through **Apache Kafka** to coordinate operations without tight coupling.

## Installation

### Prerequisites

- Docker
- Java 21
- Maven

### Clone the Repository

```bash
git clone https://github.com/madhuka2002/store-management.git
cd store-management
````

### Build Services

```bash
mvn clean install
```

### Start Services

```bash
docker-compose up --build
```

Make sure **Docker**, **Kafka**, and **PostgreSQL** are available before starting the services.

## Testing

To run integration tests:

```bash
cd integration-tests
mvn test
```

Ensure all services are up and running before executing tests.
